# PWA Icons

You need to create two icon files for the PWA:

1. `/public/icon-192.png` - 192x192 pixels
2. `/public/icon-512.png` - 512x512 pixels

You can:
- Use an online tool like https://realfavicongenerator.net/
- Create them with any image editor
- Use a simple colored square for MVP testing

For quick MVP testing, you can create simple PNG files with a solid color.
